# Sources

Governing parent: [BRAIN.md](../../BRAIN.md)

Read this guide when work relies on knowledge outside the brain, retained material may be historical, or cooperation or migration is planned.

For each source the brain actually uses, record what it owns, how an authorized actor can locate it, the observation or version context, and known availability limits. Preserve the source's operating instructions when they remain authoritative, and read their current version before acting. Referencing a source does not grant its contents authority outside their declared scope.

Distinguish a current external source from exports, excerpts, and snapshots. A snapshot is dated evidence; it does not remain current merely because it is readable.

Keep these relationships explicit:

- Cooperation leaves the external source authoritative and uses it in place.
- A migration transfers selected knowledge and records what changed ownership.
- Phased replacement deliberately runs both systems until required knowledge is transferred and the old source can be retired.

Create connection records only for real sources. Follow the [master plan](../MASTER-PLAN.md) before adding adapters or changing source ownership.
