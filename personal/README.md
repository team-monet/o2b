# Personal

Governing parent: [BRAIN.md](../BRAIN.md)

Read this guide when a task concerns the owner's own life rather than a project: life direction, family, health, routines, home, travel, and personal finance and administration. Career work, investing, and other bodies of work with their own goals belong in [project homes](../projects/README.md). The shared framework supplies this guide; the area's content belongs to the personal brain.

## Parts

The area uses the same parts as a project home, so BRAIN's habits apply unchanged. Create each part when its first item arrives.

| Part | Holds | Governed by |
|---|---|---|
| `knowledge/` | Notes a future session will need, one topic each | [Knowledge](../knowledge/README.md) |
| `workstreams/`, `INBOX.md`, `briefs/` | Open loops and commitments, findings, and handoffs | [Work](../work/README.md) |
| `guidance/STAGES.md`, `guidance/stages/` | Situations and rules that apply to the owner's personal life alone | [Guidance](../guidance/README.md) |
| `snapshot.md` | The owner's current picture, described below | This guide |
| Personal documents | Plans and records with no other home, linked from the snapshot | This guide |

Principles for personal life stay in root `guidance/PRINCIPLES.md` under a Personal scope heading.

## Snapshot page

`snapshot.md` is the page the owner reads to see where their life stands now. Its sections are the owner's choice, such as current focus, open loops, upcoming dates, routines, and plans. Each section carries the date it was last updated. It links to workstreams, notes, and documents instead of copying them, and it may embed a view, such as an Obsidian Bases view over workstream status, where the editor supports one.

Any agent may build or update it. When a task changes something the snapshot shows, update that section in place and its date, and remove what is no longer current; Git keeps the past. Change the page's sections only when the owner asks.

## Boundaries

Personal content is kept out of other tasks' context because only a personal task enters this area, but any actor with file access can read it. Keep secrets, credentials, and government or financial identifiers out of it; record where they are kept instead. Do not store other people's personal data beyond what the owner's own life requires.
