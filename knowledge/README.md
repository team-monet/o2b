# Knowledge

Governing parent: [BRAIN.md](../BRAIN.md)

Read this guide when preserving or reusing durable knowledge whose useful life extends beyond one project.

Store enough subject, source, version or time scope, and evidence for a later reader to judge whether a claim still applies. Keep observations distinguishable from synthesis. When a claim is corrected or superseded, connect the previous and current understanding where that prevents repeated mistakes.

Search results are candidates, not selected context. A reader still decides which current, relevant, and trustworthy material belongs in the task.

Project-specific knowledge remains with its [project](../projects/README.md). Create a cross-project synthesis only when reuse is real, and link its supporting project evidence. Let the reusable question determine a note's shape; add a recurring format only after use demonstrates the need.

Follow the [master plan](../MASTER-PLAN.md) before adding indexes, retrieval tools, or other framework machinery.
